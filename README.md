## 🧑‍💻 Sobre este repositorio

Bienvenido a mi espacio de aprendizaje.

Este repositorio recopila el trabajo desarrollado durante mi primer semestre de la carrera de Software en la Universidad Técnica de Ambato.

Aquí encontrarás ejercicios, actividades autónomas, prácticas experimentales, trabajos grupales y proyectos desarrollados a lo largo del semestre.

Más que almacenar códigos, este espacio representa mi evolución: desde comprender la lógica detrás de un algoritmo hasta comenzar a construir programas utilizando programación orientada a objetos.

### 🚀 UNIDAD 01 — Los primeros pasos para convertir ideas en código

<sub>FUNDAMENTOS · LÓGICA DE PROGRAMACIÓN · JAVA · C++</sub>

Primera etapa de formación enfocada en desarrollar el pensamiento lógico y aprender a transformar problemas en soluciones mediante algoritmos.

**Contenidos y actividades:**

- Variables, tipos de datos y operadores.
- Estructuras secuenciales.
- Condicionales y estructuras de selección.
- Ciclos y estructuras repetitivas.
- Validación de datos.
- Algoritmos, pseudocódigo y diagramas de flujo.
- Desarrollo de ejercicios en Java y C++.
- Actividades T1, T2, T3, T4 y T5.
- Prácticas APE 1 y APE 2.

### 🧩 UNIDAD 02 — De escribir instrucciones a construir objetos

<sub>PROGRAMACIÓN ORIENTADA A OBJETOS · JAVA</sub>

Una nueva etapa en la que los programas comienzan a organizarse mediante clases, objetos y relaciones, aplicando los principios iniciales de la programación orientada a objetos.

**Contenidos y actividades:**

- Introducción a la programación orientada a objetos.
- Creación de clases y objetos.
- Atributos y métodos.
- Constructores.
- Encapsulamiento.
- Getters y setters.
- Uso de la palabra reservada `this`.
- Relaciones entre clases y objetos.
- Objetos como atributos de otras clases.
- Manejo y escritura de archivos de texto.
- Ejercicios prácticos y actividades APE.
- Exposiciones y trabajos grupales.
