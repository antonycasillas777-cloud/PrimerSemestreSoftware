## 🧠 ¿Qué encontrarás aquí?

Esta unidad reúne las actividades y los trabajos realizados durante mi aprendizaje de la programación orientada a objetos en Java.

A diferencia de la programación inicial, en esta etapa comienzo a trabajar con clases, objetos, atributos y métodos, aprendiendo a organizar el código de una manera más estructurada y reutilizable.

Como la unidad está en desarrollo, este repositorio irá creciendo con nuevas prácticas, ejercicios, documentos y proyectos.

## 🎯 Habilidades que estoy desarrollando

- Comprender la estructura y el funcionamiento de las clases.
- Crear objetos a partir de una clase.
- Definir atributos y métodos.
- Utilizar constructores para inicializar objetos.
- Aplicar getters y setters para acceder y modificar atributos.
- Comprender el uso de `this` en Java.
- Relacionar clases mediante atributos y parámetros.
- Escribir código más organizado, reutilizable y fácil de mantener.

## 🧭 Cómo recorrer esta unidad

1. Selecciona una de las carpetas disponibles.
2. Revisa los enunciados y las instrucciones de cada actividad.
3. Analiza los códigos y ejemplos desarrollados.
4. Ejecuta los programas y practica modificando el código.
5. Consulta las nuevas actividades a medida que se incorporen.

> 📝 Esta unidad representa una nueva etapa de mi formación como programador: aprender a organizar las soluciones mediante clases y objetos, comprender cómo se relacionan y construir una base sólida para desarrollar proyectos más completos.
